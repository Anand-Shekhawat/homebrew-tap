# Homebrew tap for Noob CLI

Noob is a beginner-friendly command line: type plain English like `make folder photos`,
and learn the real commands as you go. Source: https://github.com/Anand-Shekhawat/noob-cli

```bash
brew install anand-shekhawat/tap/noob
```

Noob's own window (the app):

```bash
brew install --cask anand-shekhawat/tap/noob-app
```

To update later: `brew upgrade noob` (and `brew upgrade --cask noob-app`)
